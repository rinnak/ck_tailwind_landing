# StudyFlow — Менеджер учебных задач для студентов

Стек технологий: HTML, CSS, Tailwind CSS

## О проекте

StudyFlow — это веб-приложение для студентов, которое помогает организовать учебный процесс, отслеживать дедлайны и визуализировать прогресс.

## Особенности

**Умное расписание** — Автоматическое планирование с учётом пар и дедлайнов  
**Визуализация нагрузки** — Тепловая карта учебной активности  
**Режим "Сессия"** — Специальный инструмент для подготовки к экзаменам  
**Импорт расписания** — Загрузка .ics файлов из университета  
**Групповые проекты** — Совместная работа над заданиями
